
# 🚗 Car Safety Prediction System (Machine Learning)

## 📖 About the Project

The **Car Safety Prediction System** is a Machine Learning web application designed to predict car safety levels based on different vehicle-related features.

The application uses a trained Machine Learning model to analyze the provided inputs and generate a car safety prediction through a user-friendly web interface.

⚠️ **Important Note:** This repository is configured for **Render Deployment/Hosting**.

The project was developed using Python and Machine Learning techniques, with the web application deployed on Render for online access.

---

## 🛠️ Tools & Technologies Used

- **Machine Learning:** Scikit-learn
- **Programming Language:** Python
- **Data Processing:** Pandas, NumPy
- **Web Framework:** Flask
- **Frontend:** HTML, CSS
- **Model Storage:** Pickle / Joblib (as used in the project)
- **Cloud Hosting:** Render

## 🚀 Deploy on Render

This repository contains the web application for deployment on Render.

1. Push the project files to your GitHub repository.
2. Visit [Render](https://render.com/) and log in.
3. Select **New → Web Service**.
4. Connect your GitHub repository.
5. Configure the deployment commands.

**Build Command:**

```bash
pip install -r requirements.txt
```

**Start Command:**

```bash
python app.py
```

6. Select an appropriate instance type.
7. Click **Create Web Service** and wait for the deployment to complete.

Once deployed, Render will provide a URL to access your application.
